FLIPhub.ng

A centralized campus marketplace web platform engineered for student peer-to-peer commerce, structured item listings, and direct WhatsApp order dispatch.

← Back to selected work
The challenge

What problem needs solving?

University campuses suffer from highly fragmented and unsafe student commerce. Students buy and sell items across chaotic WhatsApp groups where posts get quickly buried, scams occur, and item discovery is virtually impossible. Sellers lack a persistent storefront, and buyers have no reliable way to search for needed textbooks, electronics, or dorm essentials.

My approach

Customer ordering flow & solution architecture

Engineered FLIPhub (fliphub.ng) as a centralized marketplace designed around low friction and instant student communication:

  • Client: Responsive web interface with real-time item cards, seller upload forms, and a public buyer request feed.
  • Backend: Node.js & Express server hosting REST endpoints, session stores, and file upload handlers.
  • Integrations: Meta WhatsApp Cloud API & Webhook for direct buyer-seller inquiries and automated student alerts.
  • DevOps: DigitalOcean cloud droplet running reverse-proxied production server with automated process supervision via systemd.
Business analysis highlights

Governance & workflow rigor

Applied structured Business Analysis methodologies to align the software with actual student behavioral habits:

  • Conducted user journey mapping for Nigerian university students to reduce listing creation time to under 60 seconds.
  • Formulated inventory control rules and created an admin queue to eliminate duplicate and spam submissions.
  • Implemented zero-leakage order workflows ensuring items remain visible until verified and marked sold by an administrator.
