## 🚀 How to Run Locally

You can preview the portfolio immediately in any browser:

### Option 1: Direct Double Click
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, or Brave.

### Option 2: Local HTTP Server (Recommended)
Open PowerShell in this directory and run:
```powershell
npx.cmd serve .
# or
python -m http.server 3000
```
Then visit: `http://localhost:3000`

## 🌐 1-Click Deployment Options

### Deploy to Vercel (Instant)
```bash
npx.cmd vercel
```

### Deploy to GitHub Pages
1. Push this folder to a GitHub repository: `https://github.com/basilnwankwo10/portfolio`
2. Go to **Repo Settings** > **Pages** > Select branch `main` and root `/`
3. Your portfolio is live for free with HTTPS!
